# Hafizh Wirya – Portfolio Website

Website portfolio statis (satu file `index.html`). Semua foto dan video dimuat dari Cloudinary
(`res.cloudinary.com/lcbagzn0`), jadi repository ini hanya berisi kode.

## Struktur
- `index.html` – halaman utama website
- `preview.html` – salinan identik `index.html` (untuk preview)

## Deploy
- **Netlify**: hubungkan repository ini, build command kosong, publish directory `/` (root).
- **GitHub Pages**: Settings → Pages → Deploy from a branch → `main` / `(root)`.
